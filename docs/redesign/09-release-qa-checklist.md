# قائمة اختبار ما بعد النشر — تدفقات المصادقة المحدّثة

> تغطي إصلاحات `4841ae4` و`9ce58e2`. تُنفَّذ يدوياً بعد أول نشر للخادم+الواجهة معاً.
> **متطلب أساسي**: حساب أدمن مفعّل عنده TOTP (من شاشة الإعدادات → المصادقة الثنائية)،
> وحساب ثانٍ بلا TOTP، وإيميل مسجل على أحدهما (SMTP مضبوط).

## 1) الدخول العادي — انحدار رجعي (يجب ألا يتأثر)
- [ ] دخول كلمة مرور صحيحة لحساب بلا TOTP → يدخل فوراً، toast ترحيب.
- [ ] حساب TOTP-mفعّل: بدون كود → يظهر حقل الكود (requires2FA) دون رسالة خطأ حمراء.
- [ ] نفسه مع كود خاطئ → «كود التحقق غير صحيح» + صف فاشل في سجل الدخول.
- [ ] نفسه بكود احتياطي (8 أرقام) في حقل الكود → يدخل، ويُستهلك الكود (يُرفض لاحقاً).
- [ ] 5 كلمات مرور خاطئة → قفل 15 دقيقة برسالة العد التنازلي.

## 2) Magic Link مع TOTP (التدفق الجديد الحرج)
- [ ] طلب رابط لحساب TOTP-mفعّل → يصل الإيميل خلال دقائق.
- [ ] الضغط على الرابط → **يظهر حوار «كود المصادقة الثنائية»** (لا دخول مباشر).
- [ ] إدخال كود صحيح → دخول كامل + toast ترحيب.
- [ ] تكرار التجربة: طلب رابط جديد، إدخال كود **خاطئ** مرة ثم الصحيح → يقبل (الرابط لم يمت).
- [ ] إلغاء الحوار (Esc) → شاشة الدخول برسالة واضحة، والرابط القديم لا يعمل مجدداً بعدها
      إن ضُغط ثانية (استهلك عند الإلغاء؟ لا — يجب أن يبقى صالحاً حتى انتهاء 15 دقيقة؛ تحقق أنه
      يعمل بإدخال الكود صحيحاً خلال الصلاحية).
- [ ] 3 أكواد خاطئة متتالية → رسالة «اطلب رابطاً جديداً».
- [ ] استخدام نفس الرابط من متصفحين بالتوازي → أحدهما فقط ينجح (الاستيلاء الذري).

## 3) Magic Link لحساب مقفل
- [ ] اقفل الحساب بخمس كلمات مرور خاطئة، ثم اطلب رابطاً وافتحه →
      **403 برسالة القفل** وليس دخولاً ناجحاً. هذه كانت الثغرة الأصلية.

## 4) البصمة WebAuthn مع TOTP (التدفق الجديد الثاني)
- [ ] سجّل بصمة على جهاز (بحساب عادي أولاً)، فعّل TOTP للحساب.
- [ ] زر «دخول بالبصمة» → مسح ناجح → **يظهر حوار الكود** (لا توكن مباشر).
- [ ] كود صحيح → دخول كامل. سجل الدخول يعرض «دخول بالبصمة + كود مصادقة ثنائي».
- [ ] كود خاطئ → رسالة، وإعادة المحاولة تتطلب **مسح بصمة جديد** (pendingId استُهلك).

## 5) QR Login — انحدار
- [ ] create/status يعملان طبيعياً بعد إضافة الـlimiter (موافقة من موبايل مسجّل).
- [ ] 20+ طلب create سريع من نفس IP → 429 برسالة «محاولات كثيرة جداً».

## 6) حدود المعدل العامة
- [ ] 21 طلب verify للرابط خلال 15 دقيقة → 429.
- [ ] استجابات 429 تظهر برسالة عربية واضحة في الواجهة لا JSON خام.

## 7) الخلفية الدورية
- [ ] (اختياري/بطيء) أدخل صفاً تجريبياً في magic_link_tokens بـcreated_at قديم
      (`now() - interval '8 days'`) وأعد تشغيل الخادم → يُحذف مع سطر 🧹 في اللوج.

## 8) ما بعد الاختبار
- [ ] سجل الدخول (شاشة الإعدادات) يعرض كل المحاولات أعلاه بأوصافها الصحيحة.
- [ ] تنبيهات الإيميل للأجهزة/الدول غير المعتادة ما زالت تصل.
