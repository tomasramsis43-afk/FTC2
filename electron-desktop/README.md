# تطبيق سطح المكتب (FTC2 Desktop)

تطبيق Electron يفتح البرنامج في نافذة مستقلة بدل المتصفح، مع نسخة محلية
من الواجهة تتحدّث تلقائياً من السيرفر عند توفر الإنترنت، وتعمل بآخر نسخة
محفوظة عند انقطاع الاتصال (القراءة والكتابة أوفلاين تتم عبر window.storage
الموجود مسبقاً في الواجهة نفسها).

## البناء (على أي جهاز Linux فيه wine، أو أي جهاز Windows)

```bash
npm install
cp -r ../frontend ./app-assets   # نسخ الواجهة الحالية قبل كل بناء
npm run dist                      # ينتج dist/FTC2 Setup X.X.X.exe
```

ملحوظة: عنوان السيرفر البعيد مضبوط في `main.js` (REMOTE_BASE) وفي أول
تشغيل يُنسخ داخل app-inline.js تلقائياً — لازم يتغيّر يدوياً فقط لو
اتغيّر رابط Render.
